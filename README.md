# Harshitha R Anchan – Portfolio

Static website (HTML, CSS, JavaScript). No build step needed.

## Publish on GitHub Pages
1. Create a new public repository on GitHub (e.g. `my-portfolio` or `HARSHITHA1530.github.io`).
2. Upload everything inside this folder (index.html, style.css, script.js, images/, .nojekyll, README.md) to the repository root.
3. Go to Settings > Pages. Under "Build and deployment", set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. Wait 1-2 minutes. Your site will be live at https://HARSHITHA1530.github.io/<repository-name>/
