# Harshitha R Anchan – Portfolio

Static website (HTML, CSS, JavaScript). No build step needed.

## Publish on GitHub Pages
1. Create a new public repository on GitHub (e.g. `my-portfolio` or `HARSHITHA1530.github.io`).
2. Upload everything inside this folder (index.html, style.css, script.js, images/, the resume PDF, .nojekyll, README.md) to the repository root.
3. Go to Settings > Pages. Under "Build and deployment", set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. Wait 1-2 minutes. Your site will be live at https://HARSHITHA1530.github.io/<repository-name>/

## Contact form (one-time activation)
The form sends messages with FormSubmit (free, no account). After the site is live, send yourself one test message
from the form. FormSubmit emails harshitaanchan2004@gmail.com an activation link - click "Activate Form" once
(check Spam too). After that, every message arrives in your inbox.
